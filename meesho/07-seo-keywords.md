# Meesho Search Keywords — Lighting

Meesho search is keyword-matched on **product name first**, then description and
attributes. Buyers type in Hinglish. The name must carry the two or three phrases they
actually type; the description carries the rest.

## How to build a Meesho product name

```
[Head keyword] + [Length/Watt/Size] + [Type words buyers use] + [Use case] + [Colour] + [Pack]
```

Example: `30 Meter LED Serial Light Jhalar Ladi Rice Light with 8 Mode Controller for Diwali Home Decoration Multicolor (Pack of 1)`

Rules: under 150 characters, no ALL CAPS, no `!!!`, no "best quality", no competitor
brand names, no emojis. Meesho QC rejects names with promotional words.

## Attribute fields that double as search filters

Fill every one Meesho offers for the category, even the optional ones. Common ones for
lights: **Colour**, **Light Colour** (Warm White / Cool White / Multicolour), **Power Source**
(Electric / Battery / USB), **Length**, **Wattage**, **Material**, **Shape**, **Number of
Lights**, **Waterproof (Yes/No)**, **Country of Origin**, **Net Quantity**, **Pack of**.

## Description template (keep under 600 characters; long ones get rejected)

```
[Product] [length/watt] for [use]. [Colour/light colour]. [Key feature: modes / remote / waterproof / warranty].
Package: [what is in the box]. Voltage: 220–240 V. [Care line].
Sold by Goyal Lights, Bhagirath Palace, Delhi — wholesale lighting market.
```

## Title A/B plan

Run each hero SKU under two names for two weeks (different catalogs, same product) and
keep the one with more orders per view. Typical winner: the one that leads with the
length or wattage, not the brand.
