# Reports

One file per ZeroGPT run, named `YYYY-MM-DD-slug.md`, based on `TEMPLATE.md`.

These are the evidence base for every threshold and pattern in the skill. Do not
change a gate value or add a marker without a report in this folder that
justifies it. When a report is filed, work through the actions checklist at the
bottom of it and then add a row to the piece history table in
`../references/learning-log.md`.

## Source PDFs

From 2026-09-18 the original detector export is filed beside its report, named
`YYYY-MM-DD-zerogpt-<slug>.pdf`. Keep them. ZeroGPT marks flagged sentences by
colour rather than by any label, and the only reliable way to recover which
sentences were highlighted is to read the fill colour of each text run out of
the PDF. Pure black is a flagged span, slate grey is clean prose. A screenshot
or a copy-paste of the page loses that distinction entirely.
